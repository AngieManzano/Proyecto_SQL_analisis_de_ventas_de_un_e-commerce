# Proyecto SQL: análisis de ventas de comercio electrónico
## Resumen (Overview)
Un comercio electronico busca mejorar su servicio y brindar un mejor servicio a sus clientes. Mi objetivo utilizar SQL Server Management Studio para analizar los datos para obtener recomendaciones para mejorar el servicio del comercio electronico.
